02/課題と方針

「合算テーブル＋逓減」はやめる

前提（やりたいこと）

ヒーローの個性として「ヒーローごとのアイテム発見テーブル」を導入したい。いまは素材テーブルをダンジョンだけが持っているが、「このヒーローはレア鉱石に強い」のように、誰を編成するかで手に入る素材が変わるようにする。

ボツにした案

その実現方法として、編成メンバー全員のテーブルをひとつに合算して回す方式を検討したが — 狙いの素材（＝特定のヒーローだけが見つけられる素材）を持たない仲間を足すほど当たりが薄まる。さらに獲得量を逓減させると伸びも中途半端になり、結局「1体運用が最適解」になってしまう。

方針 一

抽選はヒーローごとに独立

1回の抽選で、編成メンバー全員がそれぞれ自分のテーブルを引く。仲間を足しても、他のヒーローの当たりは1ミリも薄まらない。

方針 二

獲得も消費も素直に人数比例

2体で2倍、3体で3倍。変な係数を挟まないので、プレイヤーにもそのまま説明できる。

方針 三

レア素材は「ラッキー」で払う

比例で増えるのは通常素材まで。レア素材にはラッキーアイテムという別の対価を設けて、経済の蛇口を締める。

05/編成と獲得量

1回の抽選で、全員がそれぞれ引く

06/素材の見つけ方

ダンジョンが「出る物」、ヒーローが「見つける率」

素材テーブルは2層。ダンジョン共通テーブルがその場所で出うる物と重みを定め、ヒーローは品目ごとの発見率を持つ。

ダンジョン重み×発見率 (0〜10)÷10=実効重み 重みは最低100で採番、発見率は 0〜10（＝0〜100%）。すべて整数のまま計算できる。未設定の品目は 0 ＝ 見つけられない。

07/新ステータス

ラッキー — 貢ぎ物が、レア素材の入場券

スタミナとは別のゲージ。そのヒーローのラッキーアイテム（料理に限らずヒーローごとに設定）を与えたときだけ上がり、抽選のたびに減っていく。増える量はアイテムごとに設定し、コスト相応にする。

08/ダンジョン拡張

新ダンジョンは「地図」で解放

2つ目以降のダンジョンはグレードではなく、「ダンジョンの地図」を使って解放する。地図はレア枠のアイテムとして、特定のヒーローだけが見つけられる。

🗺️ 地図がレア枠で出る
発見率を持つ特定ヒーローが、ラッキー中にだけ引き当てる
→
📜 使用して解放
新ダンジョンが探検先に追加される（プレイヤーごとに解放）
→
⛰️ 新しい素材と、次の地図
新ダンジョンのテーブルに、さらに先の地図を仕込める
🗺️

解放が「レベルを上げて待つ」ではなく「地図を持つヒーローを呼び、ラッキーにして引き当てる」になる。フィギュア集め・ラッキーアイテム・発見率の3要素すべてがダンジョン拡張の鍵になり、数珠つなぎで世界を広げていける。

例: 岩壁の洞窟のテーブルに「海岸の地図」重み100・レアフラグで追加し、発見率を持つのは新ヒーローだけ（率1=10%なら実効10）。地図もItemなので既存方針（全てtradeable）に従えば市場で売買でき、「引きが弱い人は買って解放」もできる——取引可否は未決事項へ。

10/これから決めること

未決事項と実装メモ

ラッキーアイテムと「+N回」の値

どのアイテムが誰のラッキーアイテムか。+N回は「コスト相応」— 日々変動する相場でなく、品目ごとの固定テーブルで持つのが安全（相場連動だと安値の日に貢ぐのが最適解化する）。上限は成果ストック（50回）と同スケールが目安。

レアフラグの付け方

ダンジョン共通テーブルのどの品目をレア枠にするか。既存のハズレ素材7種は通常枠スタートが無難。

家具レシピと当選確率

ヒーローごとの家具の組み合わせと、日次抽選の確率。マイルーム実装の家具ラインナップ確定待ち。

新ヒーローの能力・発見率

2体目・3体目のパッシブ（スタミナ軽減・保存上限+など既存枠）と、発見率テーブルの中身。

フィギュア棚のヒント表示

未入手枠のシルエットに「ゆかりの家具」をどこまで見せるか（全部隠す／1種だけチラ見せ）。

ダンジョンの地図の取り扱い

取引可能にするか（既存方針は全てtradeable。売買を認めると「地図の相場」が生まれる）。2つ目のダンジョンと地図を持つヒーローの割り当ても要決定。

実装メモ（backend）

  • 新マスタ3つ: フィギュア発見レシピ / ヒーロー発見率テーブル / ラッキーアイテム（ヒーロー×品目→+N回）。いずれも data migration ＋ fixture 同期が必要
  • DungeonMissReward は「ダンジョン共通テーブル（重み最低100＋レアフラグ）」へ改修。発見率はヒーロー×品目の別マスタ
  • 抽選解決（simulate / claim）: 人数別間隔テーブルを単一50分に変更し、1抽選＝編成人数分のドローに。ラッキーの減衰も同じ決定的計算に乗せる
  • PlayerHero にラッキーカラム追加（残り回数・整数）
  • ダンジョン解放を grade 制から地図制へ: PlayerDungeonUnlock (player×dungeon) 追加＋地図Itemの使用API。既存の岩壁の洞窟は解放済み扱い
  • フィギュア棚は独立した新規ページ（フロント）。枠の母集合は HeroMaster (is_active) を流用し、未入手はシルエット表示
  • フィギュア郵送の日次バッチは prod cron 登録が1件増える（登録忘れに注意）
